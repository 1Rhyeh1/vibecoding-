## 一、功能一：餐厅收藏

### 1.1 功能描述

在实验 7-1 美食助手的基础上，为用户增加餐厅收藏功能。每个餐厅卡片上显示收藏图标，用户点击后可收藏 / 取消收藏，收藏的餐厅在右侧“我的收藏”面板中展示，页面刷新后收藏状态保持。

### 1.2 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 餐厅 ID | string | 是 | 高德 POI ID 或演示数据 ID，必须非空 |
| 操作类型 | `add` / `remove` | 是 | 由收藏图标的当前状态决定 |

### 1.3 输出

| 场景 | 输出 |
| --- | --- |
| 收藏成功 | 图标变为实心 ❤️，toast 提示“已添加收藏” |
| 取消收藏 | 图标变为空心 ❤️，toast 提示“已取消收藏” |
| 操作失败 | toast 提示“操作失败，请重试” |
| 达到上限 | toast 提示“收藏夹已满（最多20家）” |
| 收藏面板 | 展示名称、口味、人均、实时距离；按收藏时间倒序 |

### 1.4 约束条件

1. 最多收藏 20 家餐厅，超出时提示“收藏夹已满（最多20家）”。
2. 收藏数据使用 `localStorage` 持久化，键名 `cfm_favorites`，页面刷新后状态保持。
3. 同一餐厅不能重复收藏。
4. “我的收藏”面板位于页面右侧、地图下方。
5. 收藏面板中点击餐厅，地图自动定位到该餐厅并弹出详情。
6. 收藏数据写入前必须经过 XSS 过滤，不得存储可执行脚本。
7. 餐厅 ID 必须为字符串且非空，非法 ID 不执行操作并输出 `console.warn`。

### 1.5 验收标准

- [ ] 每个餐厅卡片上显示收藏图标（空心 / 实心）
- [ ] 点击图标可正常添加 / 取消收藏
- [ ] 刷新页面后收藏状态保持
- [ ] 收藏超过 20 家时提示上限
- [ ] 收藏面板正确展示列表，点击可定位并弹窗
- [ ] 非法餐厅 ID 不产生收藏记录
- [ ] 收藏名称中包含 `<script>` 等危险内容时被过滤

## 二、功能二：最近搜索

### 2.1 功能描述

记录用户最近使用过的搜索关键词，以标签形式展示在搜索框下方。点击标签可直接复用该关键词搜索，支持一键清空。

### 2.2 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 关键词 | string | 是 | 长度 1-40 字符，自动去除首尾空格 |

### 2.3 输出

| 场景 | 输出 |
| --- | --- |
| 搜索完成 | 关键词进入历史列表并置顶 |
| 点击标签 | 以该关键词执行搜索 |
| 点击清空 | 历史列表清空，标签行隐藏 |
| 无历史 | 不展示“最近搜索”区域 |

### 2.4 约束条件

1. 最多保留 8 条，超出时淘汰最旧的记录。
2. 使用 `localStorage` 持久化，键名 `cfm_recent_searches`。
3. 相同关键词去重，重复搜索只更新顺序，不新增。
4. 关键词写入前经过 XSS 过滤与长度校验。
5. 页面初始化时的默认搜索（“美食”）不计入历史。

### 2.5 验收标准

- [ ] 搜索后关键词出现在“最近搜索”区域
- [ ] 点击标签可复用关键词并返回结果
- [ ] 重复关键词不产生重复标签
- [ ] 超过 8 条时仅保留最近 8 条
- [ ] 刷新页面后历史保持
- [ ] 清空后区域隐藏且刷新不再出现

## 三、非功能约束

### 3.1 校验规则

1. 餐厅 ID 必须为字符串类型且非空。
2. 无效数据不执行任何写操作，并通过 `console.warn` 输出原因。
3. 关键词长度上限 40 字符，超长时拒绝搜索并提示。

### 3.2 安全约束

1. 收藏数据存储前进行 XSS 过滤，剥离 `<script>`、`<iframe>` 等危险标签。
2. 移除内联事件属性（`on*=`）与 `javascript:` 协议。
3. 所有渲染到 DOM 的文本字段使用 HTML 转义，形成“存储过滤 + 渲染转义”双层防护。

### 3.3 代码规范

1. 使用 ES6 语法：`const` / `let`、箭头函数、模板字符串。
2. 每个函数添加 JSDoc 注释，说明功能、参数与返回值。
3. 变量与函数使用驼峰命名。
4. 事件监听统一使用 `addEventListener`，不使用 `onclick` 属性。
5. 不引入第三方框架，保持单文件可运行。

### 3.4 兼容与性能

1. 桌面端左右分栏，移动端上下布局。
2. 地图标记分批渲染，每帧最多 8 个。
3. 地图初始化限制缩放级别 `[12, 18]`，关闭高分辨率与动画特效。
4. 接口失败时降级到内置演示数据，保证功能可演示。
