# 餐厅收藏与最近搜索（实验 7-2 · SDD 规范驱动开发）

在实验 7-1 校园美食地图助手的基础上，用 **SDD（Specification-Driven Development，规格驱动开发）** 新增“餐厅收藏”和“最近搜索”两个功能，并补齐校验、安全与代码规范约束。

> 本目录对应《实验 7-2：SDD 规范驱动开发：在美食助手基础上按规交付》。
> **本项目是完整独立版本**：包含 7-1 的定位、搜索、地图、筛选、智能推荐、路线规划，双击即可运行。

---

## 一、快速开始

### 方式 A：直接双击

双击 `index.html`。首次打开会弹出 Key 配置，可先点 **「先用演示数据」** 体验全部功能。

### 方式 B：本地静态服务器

```bash
python -m http.server 8080
# 或
npx serve .
```

访问 <http://localhost:8080>。

## 二、配置高德地图 Key

应用不内置任何 Key，Key 只存本机 `localStorage`，不会进入代码仓库。

在 [高德开放平台控制台](https://console.amap.com/dev/key/app) 申请：

| Key 类型 | 平台 | 用途 | 必填 |
| --- | --- | --- | --- |
| Web 服务 | Web 服务 | POI 搜索、步行路线 | 是 |
| Web 端（JS API） | Web 端（JS API） | 地图底图、校园定位（`AMap.Geolocation`） | 定位必填 |

JS API 2.0 还需配套**安全密钥 securityJsCode**，在弹窗中一并填入。

## 三、本次新增功能

### 3.1 餐厅收藏

| 能力 | 说明 |
| --- | --- |
| 收藏 / 取消 | 卡片右上心形图标，空心 / 实心切换 |
| 持久化 | `localStorage` 键 `cfm_favorites`，刷新保持 |
| 上限 | 最多 20 家，超出提示“收藏夹已满（最多20家）” |
| 去重 | 同一餐厅不能重复收藏 |
| 收藏面板 | 页面右侧、地图下方，展示名称/口味/人均/实时距离 |
| 定位联动 | 点击收藏项，地图定位并弹出详情 |
| 清空 | 二次确认后清空全部收藏 |

### 3.2 最近搜索

| 能力 | 说明 |
| --- | --- |
| 自动记录 | 每次有效搜索写入历史 |
| 持久化 | `localStorage` 键 `cfm_recent_searches` |
| 上限与去重 | 最多 8 条，重复关键词置顶不重复 |
| 一键复用 | 点击标签直接搜索 |
| 清空 | 清空历史并隐藏区域 |

### 3.3 规范约束

| 约束 | 实现 |
| --- | --- |
| 校验规则 | 餐厅 ID 必须 string 且非空；非法值 `console.warn` 并拒绝操作 |
| 安全约束 | 存储前剥离 `<script>`/`<iframe>`/`on*`/`javascript:`；渲染统一 HTML 转义 |
| 代码规范 | ES6、每个函数 JSDoc、驼峰命名、`addEventListener` |

## 七、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 收藏刷新后丢失 | 浏览器禁用了 localStorage 或使用了无痕模式 | 换普通窗口；检查浏览器存储权限 |
| 收藏按钮点击后列表跳走 | 事件冒泡未拦截 | 本实现已在收藏点击处 `stopPropagation` |
| 地图不显示 | 未填 JS API Key 或未配安全密钥 | 配置 Key；本地调试可加 `localhost` 白名单 |
| 定位失败 / 使用演示位置 | 未授权浏览器定位、非 localhost/HTTPS 打开、未填 JS API Key | 允许定位权限；用 localhost/HTTPS 打开；配置 JS API Key 与安全密钥 |
| 搜索一直演示数据 | 未填 Web 服务 Key | 配置 Key 并确认开发者认证 |
| 达到 20 家无法收藏 | 触达上限 | 取消部分收藏或点“清空” |
